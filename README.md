# Matt Puch Personal Website

Персональный веб-сайт Matt Puch, созданный с использованием современных веб-технологий.

## Технологии

- Next.js 14
- React
- TypeScript
- Tailwind CSS

## Структура сайта

- Главная страница
- Галерея
- Видео
- Новости
- Об авторе

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/mattpuch/mattpuch.github.io.git
cd mattpuch.github.io
```

2. Установите зависимости:
```bash
npm install
```

3. Запустите сервер разработки:
```bash
npm run dev
```

4. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Сборка для продакшена

```bash
npm run build
```

## Деплой

Сайт автоматически деплоится на GitHub Pages при пуше в ветку main.
